# واجهة RevSpec

## التشغيل

### Windows — دبل كليك
- دبل كليك على `RevSpec_GUI.bat` في جذر المشروع
- أو دبل كليك على `RevSpec_GUI.pyw`

### يدوي
```powershell
python gui/revspec_gui.py
# أو
python -m gui.revspec_gui
```

## الاستخدام
1. اضغط `🚀 اختر البرنامج وحلّل تلقائياً` → اختر `.exe` أو `.py` أو أي ملف
2. انتظر 10-30 ثانية
3. اضغط `📄 فتح التقرير` أو `📂 فتح مجلد النتائج`

## الميزات
- واجهة عربية بسيطة
- لا تحتاج كتابة أوامر
- تختار البرنامج وهو يفعل الباقي (ينشئ runs/<hash>/report.md + report.json)
- زر لتفعيل التحليل الديناميكي
- يعرض السجل مباشرة

## متطلبات
- Python 3.9+ مع Tkinter (مدمج)
- `pip install -e .` (يتم تلقائياً عبر .bat)

# Patcher GUI — دليل

## التشغيل
- دبل كليك `Patcher_GUI.bat`
- أو `python gui/patcher_gui.py`

## الخطوات
1. اختر البرنامج (استعراض)
2. انتظر تحميل النصوص (جدول)
3. دبل كليك على أي نص لتعديله
4. أو استخدم Batch Rename لتغيير الاسم في كل مكان
5. عدّل VersionInfo في التبويب الثاني (للـ .exe)
6. احفظ باسم جديد

## قيود
- النص الجديد بنفس الطول أو أقصر فقط
- الأيقونات والصور تحتاج Resource Hacker (سيُضاف)
